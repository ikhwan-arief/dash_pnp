# Research publication dashboard: Politeknik Negeri Padang

**[Open the dashboard](https://ikhwan-arief.github.io/dash_pnp/)**. No account is needed.

The dashboard presents the publications, citation impact, collaboration, topics, SDGs and openness of Politeknik Negeri Padang, from open bibliographic metadata. The snapshot is refreshed weekly; the date of the current snapshot is shown on the dashboard and in `data/manifest.json`. If a refresh fails, the last good version stays online.

This is an independent dashboard built on open bibliographic metadata. It is not an endorsed official statistic of Politeknik Negeri Padang. The metadata is CC0; rights to the works it describes belong to their respective holders.
